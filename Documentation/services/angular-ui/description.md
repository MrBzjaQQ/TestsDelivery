# Angular 21 UI - Описание

## Обзор

Angular 21 UI — современное фронтенд-приложение для системы TestsDelivery, построенное на Angular 21 и SCSS. Предоставляет пользовательский интерфейс для студентов, преподавателей и администраторов.

## Ролевая модель доступа

Приложение поддерживает три роли пользователей:

| Роль | Описание |
|------|----------|
| **Student** | Прохождение тестов, просмотр результатов, управление профилем |
| **Teacher** | Создание тестов, управление вопросами, просмотр результатов студентов, аналитика |
| **Admin** | Полный доступ к системе, управление пользователями, конфигурация системы |

## Основные возможности

### Портал студента
- Просмотр доступных тестов со статусом и сроками
- Прохождение тестов с таймером в реальном времени
- Поддержка различных типов вопросов (один ответ, несколько ответов, текстовый ответ)
- Просмотр детальных результатов с обратной связью
- Отслеживание личного прогресса и статистики
- Пересдача тестов (если разрешено)

### Панель преподавателя
- Создание и управление банками вопросов
- Создание тестов из банков вопросов
- Назначение тестов группам/студентам
- Просмотр результатов студентов и аналитики
- Управление шаблонами тестов
- Экспорт результатов и отчётов

### Панель администратора
- Управление пользователями (CRUD операции)
- Назначение ролей
- Конфигурация системы
- Аудит логов
- Мониторинг состояния системы

## Принципы проектирования

1. **Standalone Components** — архитектура независимых компонентов Angular 21
2. **Signals** — реактивное управление состоянием с помощью Angular signals
3. **SCSS-модули** — изолированные стили с CSS-модулями
4. **Адаптивный дизайн** — подход mobile-first
5. **Доступность** — соответствие WCAG 2.1 AA
6. **Производительность** — ленивая загрузка, стратегия OnPush

## Коммуникация с Backend

Приложение взаимодействует с **BffPortalService** как единой точкой входа:

```
Angular UI ──> BffPortalService ──> Микросервисы
    │                │
    │                ├── IdentityService
    │                ├── QuestionManagementService
    │                ├── StudentManagementService
    │                ├── TestCheckingService
    │                └── NotificationService
```

> **Примечание:** Аутентификация (login, register, refresh, logout) выполняется через IdentityService (порт 8081), но Angular UI взаимодействует с ним опосредованно через BffPortalService.

## Используемые API-эндпоинты

> **Примечание:** Endpoints аутентификации (login, register, refresh, logout) направляются через BffPortalService к IdentityService (порт 8081).

| Эндпоинт | Назначение |
|----------|------------|
| `POST /api/v1/auth/login` | Аутентификация пользователя |
| `POST /api/v1/auth/register` | Регистрация пользователя |
| `POST /api/v1/auth/refresh` | Обновление токена |
| `GET /api/v1/portal/students/profile` | Профиль студента |
| `GET /api/v1/portal/tests/available` | Доступные тесты |
| `POST /api/v1/portal/tests/{id}/start` | Начать тест |
| `GET /api/v1/portal/tests/{id}/questions` | Вопросы теста |
| `POST /api/v1/portal/tests/{id}/submit` | Отправить тест |
| `GET /api/v1/portal/tests/{id}/results` | Результаты теста |
| `GET /api/v1/portal/groups/{id}/analytics` | Аналитика группы |

## Безопасность

- Аутентификация на основе JWT-токенов
- Автоматическое обновление токена
- Защита маршрутов по ролям (route guards)
- HTTP-интерцепторы для заголовков авторизации
- Защита от XSS
- Защита от CSRF (на уровне backend)
